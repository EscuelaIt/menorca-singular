## Menorca Singular

Menorca Singular es un ejemplo práctico del **Curso de Diseño Web con IA** de EscuelaIT. El proyecto recrea la web de una empresa ficticia que ofrece rutas culturales guiadas por especialistas, con un enfoque en grupos pequeños, patrimonio y reservas directas.

El ejemplo muestra cómo llevar una idea de diseño desde el brief hasta interfaces responsivas y accesibles: portada, ficha de una ruta cultural, área del viajero y guía de estilo viva. La identidad visual utiliza el concepto de «cuaderno de campo», con una estética editorial inspirada en el trabajo arqueológico e histórico de Menorca.

Está construido con **HTML y CSS estáticos**, sin frameworks ni JavaScript. El sitio está pensado primero para móvil y cuenta con tipografía propia, componentes reutilizables, imágenes adaptativas y controles adaptados a navegación con teclado.
