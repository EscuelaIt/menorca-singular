Esta página no forma parte del ejemplo

Menorca Singular es el proyecto de ejemplo de un curso de diseño web asistido por IA. Para enseñar el proceso completo se han diseñado tres páginas de referencia y la guía de estilo que las sostiene. El resto de la web (catálogo, otras rutas, reservas, contacto y textos legales) se construiría a partir de ellas.
